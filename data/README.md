# Data

Price files are not included (licence). Put them here:

- `xauusd-m1-bid-2024-01-01-2026-10-31.csv` — Dukascopy XAUUSD 1-minute bid export (CSV with a `timestamp` column in ms, UTC).
- `EURUSD_M1.csv`, `GBPUSD_M1.csv`, `US30_M1.csv` — any 1-minute source; MetaTrader 5 exports (tab separated, UTC) and Dukascopy CSVs both load.

See the main README for details.
